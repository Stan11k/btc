# BTC Spread Monitor — Binance ⇄ Aster

Односторінковий сайт (без бекенду), який у реальному часі показує ціну BTC на
**Binance Futures** та **Aster Futures** і сигналізує (звук + push-сповіщення
браузера + запис у журнал), коли спред між біржами перевищує заданий поріг
(за замовчуванням 2%).

## Як це працює

- Сторінка підключається напряму з браузера до публічних WebSocket-потоків
  bookTicker кожної біржі (`wss://fstream.binance.com/...`,
  `wss://fstream.asterdex.com/...`) — це найкращі bid/ask у режимі реального
  часу, без проміжного сервера й без додаткової затримки.
- Якщо WebSocket недоступний (наприклад, мережа блокує з'єднання), сторінка
  автоматично перемикається на швидкий REST-опитування (раз на секунду) і
  далі періодично намагається відновити WebSocket.
- Спред рахується двома способами:
  - **Mid-price спред** — різниця середніх цін (bid+ask)/2 у відсотках. Це
    основна метрика, за якою спрацьовує сповіщення.
  - **Арбітражний (виконуваний) спред** — найкращий з варіантів
    «купити на одній біржі за ask / продати на іншій за bid», тобто реальний
    прибуток, який можна було б зафіксувати прямо зараз.
- Поріг сповіщення можна змінювати прямо на сторінці (поле «Поріг
  сповіщення, %»). Кожне спрацювання потрапляє в журнал знизу зі
  збереженням часу, спреду та цін.

## Запуск

Це статичний сайт (`index.html` + `style.css` + `app.js`), бекенд не потрібен.

### Локально
Просто відкрийте `index.html` у браузері (подвійний клік або
`open index.html`).

### Хостинг (щоб мати посилання, доступне з будь-якого пристрою)
Підійде будь-який статичний хостинг:

- **GitHub Pages**: Settings → Pages → Deploy from branch → оберіть цю гілку
  і корінь репозиторію.
- **Netlify / Vercel**: перетягніть папку з файлами в інтерфейс деплою —
  сайт з'явиться за секунди.

## Важливо

- Binance інколи недоступний з деяких країн (наприклад, США) через
  гео-обмеження — у такому разі допоможе VPN або хостинг сторінки в іншому
  регіоні.
- Для звукових сповіщень браузеру потрібна хоча б одна взаємодія
  користувача зі сторінкою (клік) — це стандартне обмеження браузерів,
  не проблема сайту.
- Для push-сповіщень браузер запитає дозвіл — підтвердьте його, якщо
  хочете отримувати сповіщення навіть коли вкладка не активна.
- Символ за замовчуванням — `BTCUSDT` на ф'ючерсах обох бірж. Змінити пару
  можна у `app.js` (об'єкт `CONFIG`).
